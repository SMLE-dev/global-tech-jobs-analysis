# Global Tech Jobs Analysis Dashboard

## Project Overview

An interactive Microsoft Excel dashboard built to analyze a synthetic global technology-jobs dataset.

The project explores job distribution, salary differences, experience levels, job roles, and work arrangements across countries and regions.

## Business Questions

The analysis was designed to answer:

* Which regions have the most technology jobs?
* Which regions have the highest average salaries?
* Which technology roles are most common?
* Which countries have the highest average salaries?
* How are jobs distributed across remote, hybrid, and on-site work?
* Which roles have the highest proportion of remote positions?
* How does salary vary by experience level?
* How does salary vary across different job roles?

## Key Findings

Using the 15-job sample dataset:

* Data Analyst was the most common role, representing **40%** of the dataset.
* North America had the highest average regional salary at **$86,750**.
* The United States had the highest average country salary at **$95,000**.
* **5 of 15 jobs (33.3%)** were remote.
* Data Analyst had the highest proportion of remote positions, with **3 of 6 jobs (50%)** being remote.
* Average salary increased from **$18,600 for entry-level roles** to **$53,666.67 for mid-level roles** and **$85,250 for senior roles** in this sample.

## Dashboard Features

The dashboard includes:

* Dynamic KPI cards
* Country and Region slicers
* Interactive PivotCharts
* Salary analysis
* Job-role analysis
* Work-type analysis
* Experience-level analysis
* Dynamic Key Insights

The dashboard updates when the user filters the data using the Country and Region slicers.

## Important Data Note

The dataset used in this project is **synthetic practice data** created for learning and portfolio development.

The salary figures and job distributions should **not** be interpreted as real global technology labour-market statistics.

## Project Purpose

This project was created to practice the end-to-end data-analysis workflow:

**Raw Data → Data Preparation → Analysis → Visualization → Dashboard → Insights**

It also demonstrates my ability to use Excel to transform structured data into an interactive analytical dashboard.
